# spring-dynamic-scheduler

> English | [中文](README.zh-CN.md)

Dynamic scheduled-task control: task configuration is stored in a database (embedded H2); tasks can be added, removed, started and stopped at runtime.

## Run

No external dependencies.

```bash
./gradlew :spring-dynamic-scheduler:bootRun
```
