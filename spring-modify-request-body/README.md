# spring-modify-request-body

> English | [中文](README.zh-CN.md)

Modify the RequestBody in one place: a ControllerAdvice rewrites the request body before argument resolution.

## Run

No external dependencies.

```bash
./gradlew :spring-modify-request-body:bootRun
```
