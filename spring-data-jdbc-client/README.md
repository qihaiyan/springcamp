# spring-data-jdbc-client

> English | [中文](README.zh-CN.md)

Spring Boot 3.2 JdbcClient: CRUD with the fluent JDBC API. Data in embedded H2.

## Run

No external dependencies.

```bash
./gradlew :spring-data-jdbc-client:bootRun
```
