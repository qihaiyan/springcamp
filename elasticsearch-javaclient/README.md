# elasticsearch-javaclient

Elasticsearch 新版 Java 客户端（elasticsearch-java）使用示例：文档增删改查与检索。

## 运行

前置条件：本地 Elasticsearch（`localhost:9200`）。启动后由 CommandLineRunner 自动执行示例并输出结果。

```bash
./gradlew :elasticsearch-javaclient:bootRun
```
