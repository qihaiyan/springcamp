# spring-easy-rule

> English | [中文](README.zh-CN.md)

Easy Rules engine integration: rules defined in `src/main/resources/demo-rule.yml`, with rule groups and short-circuit strategies.

## Run

No external dependencies.

```bash
./gradlew :spring-easy-rule:bootRun
```
