# spring-data-flex-query

> English | [中文](README.zh-CN.md)

Flexible Spring Data JPA queries: safely composing dynamic query conditions without SQL injection. Data in embedded H2.

## Run

No external dependencies.

```bash
./gradlew :spring-data-flex-query:bootRun
```
