# spring-data-envers-conditional

> English | [中文](README.zh-CN.md)

Conditional auditing with Spring Data Envers: audit records are saved only when specific fields change. Data in embedded H2.

## Run

No external dependencies.

```bash
./gradlew :spring-data-envers-conditional:bootRun
```
