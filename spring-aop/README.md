# spring-aop

> English | [中文](README.zh-CN.md)

Spring AOP example: @Before/@After advice, a custom @TrackTime annotation and an execution-time aspect.

## Run

No external dependencies.

```bash
./gradlew :spring-aop:bootRun
```
