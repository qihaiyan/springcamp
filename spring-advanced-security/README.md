# spring-advanced-security

Spring Security 高级用法：自定义 AuthenticationProvider、UserDetailsService、登录入口与鉴权控制。

## 运行

无外部依赖。启动后访问 `http://localhost:8080`，按登录引导体验自定义认证流程。

```bash
./gradlew :spring-advanced-security:bootRun
```
