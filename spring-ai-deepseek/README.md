# spring-ai-deepseek

Spring AI 集成 DeepSeek 大模型：对话、流式输出、推理内容与 Function Calling。

## 运行

前置条件：DeepSeek API Key，修改 `src/main/resources/application.properties` 中的 `spring.ai.deepseek.api-key`。

```bash
./gradlew :spring-ai-deepseek:bootRun
```
