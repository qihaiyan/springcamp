# spring-kafka

> English | [中文](README.zh-CN.md)

Three ways to use Kafka in Spring: @KafkaListener, MessageListenerContainer and Spring Cloud Stream.

## Run

Demonstrated by unit tests with @EmbeddedKafka — no Kafka installation required:

```bash
./gradlew :spring-kafka:test
```
